Enterprise Features

Engineered for Commercial Fintech Standards

Smart Cascading Payment

Multi-source payment routing that automatically draws remaining balance from the Primary Account if spending pocket funds are insufficient, executing seamlessly in a single Room @Transaction.

Round-Up Micro-Savings

Rounds up non-integer QRIS payments to the nearest Rp 5,000 threshold and automatically deposits the change into a high-yield "Celengan Receh" pocket.

Fintech Security Shield

FLAG_SECURE screen recording/screenshot prevention, ProcessLifecycleOwner 60s background inactivity auto-lock, Biometric authentication, and balance masking.

Native E-Statement PDF Engine

Generates official A4 bank statements with letterhead, security watermark, account balance summary, and mutation tables using Android's native PdfDocument engine.

Idempotency & Payment States

UUID-based idempotency key verification preventing duplicate payment requests, combined with an explicit Payment State Machine (SUCCESS, PENDING, REVERSED).

QRIS Camera & Gallery Scanner

CameraX integration for live QRIS scanning alongside Google ML Kit image analysis for scanning QR code images selected from the gallery.

Architecture & Quality

Clean Architecture + Unidirectional Data Flow (MVI)

PocketPay is architected using strict Clean Architecture boundaries and the MVI (Model-View-Intent) presentation pattern to deliver predictable state management and high testability.

1

Predictable State Machine

UI emits immutable Intents (HomeUiIntent) and listens to single StateFlow updates (HomeUiState).

2

Atomic Room Persistence

All complex financial operations execute inside SQL @Transaction blocks, preventing partial state failures.

3

Dependency Injection with Hilt

Loose coupling across data, domain, and presentation layers managed by Dagger Hilt.
